01

Requests — طلب صفحة ويب

مكتبة requests هي أداة بايثون اللي بتخليك "تطلب" أي صفحة ويب زي ما المتصفح بيعمل بالظبط، وترجّعلك المحتوى (HTML) عشان تشتغل عليه. أول خطوة في أي سكريبت scraping.

get_page.py
import requests

url = "https://books.toscrape.com/catalogue/page-1.html"
response = requests.get(url)
response
▸ Output
<Response [200]>
status_code.py
response.status_code
▸ Output
200
200 يعني إيه؟ ده HTTP status code بيقول إن الطلب نجح والصفحة اتجابت بنجاح. أي رقم من نوع 4xx (زي 404) أو 5xx معناه فيه مشكلة — الصفحة مش موجودة أو السيرفر عنده خطأ.
جرب بنفسك: print(response.text) بتطبعلك كل كود الـ HTML الخام للصفحة كـ string واحد طويل — ده اللي هنبدأ نحلله في الموضوع الجاي.
02

BeautifulSoup — تحويل النص لكائن قابل للتحليل

response.text مجرد نص طويل عادي — مش عارف تدوّر فيه بسهولة. BeautifulSoup بتحوّله لكائن (object) منظّم بشكل شجري، تقدر تتنقل فيه وتدوّر بالتاج أو الكلاس أو أي خاصية تانية.

soup = BeautifulSoup(response.text, 'html.parser')

03

get_text() — استخراج النص من أي عنصر

أي عنصر HTML لما تجيبه بـ BeautifulSoup بيكون فيه التاجات نفسها كمان، مش بس النص. get_text() بتشيل كل التاجات وتديك النص الصافي بس اللي المستخدم شايفه في المتصفح.

title_raw.py
print(soup.title.get_text())
▸ Output

    All products | Books to Scrape - Sandbox
title_strip.py
print(soup.title.get_text(strip=True))
▸ Output
All products | Books to Scrape - Sandbox
خطر شائع: لاحظ الفرق — النسخة من غير strip=True فيها أسطر فاضية ومسافات زيادة (زي ما HTML بيكون متعمّل indent في السورس)، والنسخة التانية نضيفة تمامًا. دايمًا استخدم strip=True إلا لو محتاج المسافات لسبب معين.

05

find_all() — البحث عن كل العناصر المطابقة

find_all('tag') بترجّع لستة (list) فيها كل العناصر اللي بتطابق التاج، مش عنصر واحد بس. حتى لو لقيت عنصر واحد بس مطابق، برضو بترجعه جوه لستة.

القاعدة الذهبية: find() = عنصر واحد أو None. find_all() = لستة (ممكن تكون فاضية [] لو مفيش تطابق، بس مش هتدّيك error). استخدم find لما تكون متأكد إن العنصر واحد بس (زي title)، وfind_all لما تعرف إن فيه أكتر من واحد (زي كل بطاقات الكتب في صفحة).
06

البحث بالـ class وتنظيف نصوص متعددة

تقدر تضيف class_='...' لأي find أو find_all عشان تحدد العنصر بدقة أكتر. ولو عندك لستة عناصر وعايز تنضّف نص كل واحد فيهم، تقدر تستخدم list comprehension أو map + lambda.

print(side_categories[0].get_text(strip=True))

09

تجميع الاستخراج في دالة واحدة

بدل ما نكرر نفس أسطر الاستخراج لكل كتاب لوحده، بنعمل دالة توحّد العملية على كل الكتب مرة واحدة، وترجّع 3 لستات (اسم، سعر، توفر) بنفس فكرة الـ return المتعدد اللي اتعلمناها قبل كده.

extract_book_info.py
def extract_book_info(listofbooks):
    book_name = []
    price = []
    availability = []
    for book in listofbooks:
        book_name.append(book.find('h3').get_text())
        price.append(book.find('p', class_='price_color').get_text())
        availability.append(
            book.find('p', class_='instock availability').get_text(strip=True)
        )
    return book_name, price, availability

book_name, price, availability = extract_book_info(books)
تصغير الدالة (زي ما اتعلمنا قبل كده): الدالة دي بتاخد أي لستة كتب (مش بس الصفحة دي) وترجّع 3 لستات جاهزة. ده معناه تقدر تنادي نفس الدالة على أي صفحة تانية من books.toscrape.com من غير ما تكرر كود.
