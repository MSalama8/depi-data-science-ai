الحلقات التكرارية والتعامل مع الأخطاء

مرجع مذاكرة تفاعلي مبني على أمثلة الجلسة نفسها — كل نقطة فيها شرح مبسط، الكود زي ما اتكتب في المحاضرة، والناتج المتوقع جنبه.

01

For Loop — حلقة التكرار الأساسية

الـ for بتمشي على عناصر أي "iterable" (لستة، سترينج، ...) عنصر عنصر، وتنفّذ نفس الكود لكل عنصر.

for_basic.py
lst = [2,3,4,5,6,7,7]
for i in lst:
    print(i)
▸ Output
2
3
4
5
6
7
7
even_odd.py
lst = [2,3,4,5,6,7,7]
even = []
odd = []
for i in lst:
    if i % 2 == 0:
        even.append(i)
    else:
        odd.append(i)
print(even)
print(odd)
▸ Output
[2, 4, 6]
[3, 5, 7, 7]
جرب بنفسك: اطبع جدول الضرب في 2 من 1 لـ 12 باستخدام for i in lst — زي ما اتعمل في المحاضرة: f"{i} X 2 = {i*2}".
02

Range()

range(start=0, stop, step=1) بتولّد أرقام متتابعة من غير ما تحتاج تكتب لستة يدويًا.

range_example.py
# range(start=0 , stop or end , step=1)
for i in range(1,13):
    print(f"{i} X 2 = {i*2}")
▸ Output
1 X 2 = 2
2 X 2 = 4
3 X 2 = 6
...
12 X 2 = 24
ملاحظة: range(1,13) بيوقف قبل 13 — يعني آخر رقم فعلي هو 12.
03

For في سطر واحد — List Comprehension

أي حلقة for بسيطة بتبني لستة جديدة، ممكن تتكتب في سطر واحد بالشكل: [expression for item in list].

long_way.py
lst2 = []
lst = [4,5,6,7,8]
for i in lst:
    lst2.append(i*2)
one_line.py
lst = [4,5,6,7,8]
[i * 2 for i in lst]
# [8, 10, 12, 14, 16]
with_condition.py
lst = [4,5,6,7,8]
even = [i for i in lst if i % 2 == 0]
# [4, 6, 8]

odd = [i for i in lst if i % 2 != 0]
# [5, 7]
clean_text.py
text = "qwertyuio#$pasdfg..."
schar = "!@#$%^&*()?+_"
''.join([i for i in text if i not in schar])
# 'qwertyuiopasdfghjklzxcvbnm'
جرب بنفسك: اجمع عناصر لستة باستخدام for عادي: s = s + i — جرب بعدها تعمل نفس الفكرة بس بـ sum(lst).
04

الحلقات المتداخلة (Nested For)

حلقة جوه حلقة — مفيدة جدًا مع اللستة اللي جواها لستات (زي المصفوفات/matrices).

nested_basic.py
lst = [[2,3,4], [3,4,5]]
for i in lst:
    print(i)
    for j in i:
        print(j)
    print("########")
▸ Output
[2, 3, 4]
2
3
4
########
[3, 4, 5]
3
4
5
########
matrix_add.py
m = [[1,2,3],[2,3,4],[4,5,6],[6,7,8]]
w = [[1,2,2],[6,3,4],[4,2,6],[6,9,8]]
S = []
for i in range(len(m)):
    s = []
    for j in range(len(m[0])):
        s.append(m[i][j] + w[i][j])
    S.append(s)
with_numpy.py
import numpy as np
m = np.array([[1,2,3],[2,3,4],[4,5,6],[6,7,8]])
w = np.array([[1,2,2],[6,3,4],[4,2,6],[6,9,8]])
m + w   # نفس النتيجة بسطر واحد!
ليه numpy؟ نفس عملية جمع المصفوفتين اللي محتاجة حلقتين متداخلتين، numpy بتعملها بسطر واحد وأسرع بكتير.
05

Break · Continue · Pass

تلات كلمات بتتحكم في مسار الحلقة: break يوقفها خالص، continue يقفز للعنصر اللي بعده، pass "متعمليش حاجة" (placeholder).

break.py
lst = [2,3,4,5,6,7]
for i in lst:
    if i == 5:
        break
    print(i)
# 2 3 4  (بيوقف تمامًا)
continue.py
lst = [2,3,4,5,6,7]
for i in lst:
    if i == 5:
        continue
    print(i)
# 2 3 4 6 7  (بيتخطى الـ5 بس)
pass.py
for i in range(10):
    pass       # كود مؤقت لسه هنكتبه

def say_hello():
    pass       # فانكشن لسه فاضية

class A:
    pass       # كلاس لسه فاضي
06

Enumerate

enumerate(lst) بترجع كل عنصر مع رقم مكانه (index) مع بعض، في هيئة زوج (index, value).

enumerate.py
lst = [2,3,4,5,6,7]
for i, v in enumerate(lst):
    print(f'Index of {v} is {i}')
▸ Output
Index of 2 is 0
Index of 3 is 1
Index of 4 is 2
Index of 5 is 3
Index of 6 is 4
Index of 7 is 5
ربط بالقواميس: dict([i for i in enumerate(lst)]) بتحول اللستة لقاموس {index: value} — جرّبها في الجزء الجاي.
07

Dictionaries — القواميس

القاموس بيخزن بيانات على شكل key: value. عنده تلات دوال أساسية للتعامل مع محتواه.

build_dict.py
lst = [2,3,4,5,6,7]
d = dict([i for i in enumerate(lst)])
# {0: 2, 1: 3, 2: 4, 3: 5, 4: 6, 5: 7}
▸ الدوال التلاتة
d.keys()   → dict_keys([0,1,2,3,4,5])
d.values() → dict_values([2,3,4,5,6,7])
d.items()  → dict_items([(0,2),(1,3),...])
08

While Loop

الـ while بيفضل يكرر طول ما الشرط True. لازم يكون في حاجة جوه الحلقة بتغيّر الشرط، وإلا الحلقة تبقى "لا نهائية" (infinite loop).

while_basic.py
x = 1
while x <= 10:
    print(x)
    x += 1
▸ Output
1
2
3
...
10
while_true_break.py
while True:
    x = input("Enter char: ")
    if x == 'A': print("A")
    elif x == 'B': print("B")
    else:
        print("Wrong char")
        break   # لازم break أو الشرط يبقى False عشان توقف
خطر شائع: while True من غير break جواها = حلقة لا نهائية بتعلّق البرنامج.
09

Try / Except — التعامل مع الأخطاء

بنحط الكود اللي ممكن يسبب خطأ جوه try، ولو حصل خطأ بينفذ اللي جوه except بدل ما البرنامج يقف فجأة.

generic_except.py
try:
    age = int(input("Please enter your age: "))
except:
    print("Please enter your age in number")
print("s2")
specific_except.py
try:
    print(10/0)
except ZeroDivisionError:
    print("ZeroDivisionError")

try:
    d = {'key':'value'}
    print(d['key2'])
except KeyError:
    print("KeyError")
exception_as_e.py
try:
    print(10/0)
except Exception as e:
    print("Error", e)
# Error division by zero
else_finally.py
try:
    d = {'key':'value'}
    print(d['key'])
except:
    print("Error")
else:          # لو مفيش خطأ
    print("No Error")
finally:        # بتتنفذ دايمًا
    print("End")
الفرق: except: يمسك أي خطأ. except ValueError: يمسك نوع محدد بس. except Exception as e: يمسك أي خطأ ويسيبك تشوف رسالته.
