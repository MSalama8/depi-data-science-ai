01

العمليات الحسابية الأساسية

بايثون فيها كل العمليات الحسابية المعتادة، وبتتفرق شوية عن اللغات التانية في القسمة: / بترجع رقم عشري دايمًا، و // بترجع القسمة الصحيحة (Floor Division).

arithmetic.py
x = 15
y = 3
x + y    # جمع
x - y    # طرح
x * y    # ضرب
x / y    # قسمة عادية
x % y    # باقي القسمة
x ** y   # الأس (القوة)
x // y   # قسمة صحيحة
▸ Output (x=15, y=3)
x + y  = 18
x - y  = 12
x * y  = 45
x / y  = 5.0
x % y  = 0
x ** y = 3375
x // y = 5
لاحظ: / نتيجتها دايمًا float حتى لو القسمة مظبوطة (5.0)، أما // فبتقرّب لتحت وتديك عدد صحيح.
جرب بنفسك: نفس الكود بالظبط بيشتغل على أي رقمين — جرب x=10, y=10 وبعدين x=40, y=5 وشوف الفرق في القسمة والباقي.
▸ x=10, y=10
x + y  = 20
x - y  = 0
x * y  = 100
x / y  = 1.0
x % y  = 0
x ** y = 10000000000
x // y = 1
▸ x=40, y=5
x + y  = 45
x - y  = 35
x * y  = 200
x / y  = 8.0
x % y  = 0
x ** y = 102400000000000000...
x // y = 8
02

Built-in Functions — الدوال الجاهزة

بايثون جايالك بدوال جاهزة تقدر تستخدمها على طول من غير ما تكتبها، زي print() و type() و id().

builtin_basic.py
print("s2")

x = 10
type(x)     # نوع المتغير
id(x)       # عنوان المتغير في الذاكرة
▸ Output
s2
<class 'int'>
11645640   # عنوان مختلف كل مرة
join_chars.py
"".join(['a','h','m','e','d'])
# 'ahmed'
▸ Output
'ahmed'
جرب بنفسك: استخدم id() على متغيرين ليهم نفس القيمة وشوف هل العنوان واحد ولا لأ.
03

بنية الدالة (Pre-Defined Function)

الدالة بتتبنى بـ def، وبتتلخص في 3 أشكال حسب لو فيها مدخلات (parameters) و/أو مخرجات (return) ولا لأ.

function_shapes.py
# شكل 1: من غير مدخلات ومن غير return
def function_name():
    statements....

function_name()

# شكل 2: بمدخلات وبـ return
def function_name(param1, param2, ....):
    statements....
    return value1, value2, ....

function_name(arg1, arg2, ....)
v1, v2, .... = function_name(arg1, arg2, ....)
القاعدة: أي دالة ممكن تاخد مدخلات أو لأ، وترجّع قيمة أو لأ — الأربع تركيبات كلها ممكنة، وهنشوفهم واحدة واحدة.
04

من غير مدخلات ومن غير Return

أبسط شكل للدالة: بتنفّذ أوامرها بس، ومش بترجّع أي قيمة. لو خزّنت ناتجها في متغير هتلاقيه None.

say_hello_v1.py
def say_hello():
    print("Hello,..")

x = say_hello()
print(x)
▸ Output
Hello,..
None
ليه None؟ الدالة مفيهاش return، فبايثون بترجّع None تلقائيًا لأي حد يحاول يخزّن ناتجها.
05

دالة بمدخلات، من غير Return

تقدر تبعت القيم بالترتيب (positional) أو بالاسم (keyword)، وتقدر تدّي قيمة افتراضية (default) للمدخل لو مش هيتبعت.

say_hello_v2.py
def say_hello(name, age=0):
    print("Hello,", name, "Your age is", age)

say_hello("s2")
say_hello("Ahmed", 30)
say_hello(name="Ahmed", age=30)
▸ Output
Hello, s2 Your age is 0
Hello, Ahmed Your age is 30
Hello, Ahmed Your age is 30
order_matters.py
say_hello(30, "Ahmed")
# positional: بترتيب المكان، مش المعنى
▸ Output
Hello, 30 Your age is Ahmed
خطر شائع: لما تبعت القيم positional، الترتيب هو اللي بيحدد مين لمين — لو بدّلت الترتيب هتتبدل المعاني زي المثال اللي فوق. الحل: استخدم keyword arguments زي age=30, name="Ahmed" عشان الترتيب مايفرقش.
06

دالة بمدخلات و Return

هنا الدالة بترجّع قيمة (أو أكتر) تقدر تخزّنها وتستخدمها بعد كده. الدالة لازم تتعرّف الأول قبل ما تُستدعى، وإلا هيطلع NameError.

add.py
def add(num1, num2):
    s = num1 + num2
    return s

res = add(10, 20)
print(res)
▸ Output
30
even_odd_sum.py
def even_odd_sum(lst):
    even, odd = [], []
    s_even, s_odd = 0, 0
    for i in lst:
        if i % 2 == 0:
            even.append(i); s_even += i
        else:
            odd.append(i); s_odd += i
    return even, s_even, odd, s_odd

l = [1,2,3,2,3,4,3,4,5,6]
even, s_even, odd, s_odd = even_odd_sum(l)
▸ Output
Even [2, 2, 4, 4, 6] Sum 18
Odd  [1, 3, 3, 3, 5] Sum 15
تقسيم المهام (تصغير الدالة): بدل ما دالة واحدة تعمل كل حاجة، ممكن تفصل الجمع لوحده في دالة get_sum(seq) وتناديها جوه even_odd_sum — الكود بيبقى أنضف وأسهل في الصيانة.
07

*args — عدد غير محدد من المدخلات

لو مش عارف قدّ إيه هيتبعتلك من قيم، استخدم *args — بتجمعهم كلهم في tuple واحد تقدر تلف عليه بـ for.

star_args.py
def add(*num):   # num >>> (val1, val2, ...)
    s = 0
    for i in num:
        s += i
    return s

add()
add(1)
add(1,2)
add(1,2,3)
▸ Output
add()      → 0
add(1)     → 1
add(1,2)   → 3
add(1,2,3) → 6
ليه مش بس list؟ قبل *args كنت مضطر تعمل دالة لكل عدد مدخلات (add(a,b), add(a,b,c)...) — *args بتحل المشكلة دي بمرونة كاملة.
08

**kwargs — مدخلات على شكل قاموس

**kwargs بتجمع أي مدخلات بالاسم (key=value) في dictionary واحد — مفيدة جدًا لما عدد وأسماء المدخلات مش ثابتة.

double_star.py
def obj(**b):
    print(b.keys())
    print(b.values())
    return b

obj(name="s2", age=30)
▸ Output
dict_keys(['name', 'age'])
dict_values(['s2', 30])
{'name': 's2', 'age': 30}
kwargs_pandas.py
import pandas as pd

def dataframe(**params):
    return pd.DataFrame(params)

dataframe(name=["s2","s3"], age=[30,23])
▸ Output
   name  age
0   s2    30
1   s3    23
جرب بنفسك: ابعت لـ dataframe() عمود تالت زي grade=["A","B"] وشوف الـ DataFrame بيتوسّع تلقائي.
09

map() — تطبيق دالة على كل عنصر

map(function, seq) بتطبّق نفس الدالة على كل عنصر في اللستة، وبترجّع map object لازم تحوّله لـ list() عشان تشوف قيمه — وبيتستهلك مرة واحدة بس.

map_basic.py
def check(num):
    return "Even" if num % 2 == 0 else "Odd"

lst = [1,2,3,4,5]
result = list(map(check, lst))
▸ Output
['Odd', 'Even', 'Odd', 'Even', 'Odd']
map_once_only.py
res = map(check, lst)
print(list(res))   # أول مرة: يطلع كل القيم
print(list(res))   # تاني مرة: فاضي!
▸ Output
['Odd', 'Even', 'Odd', 'Even', 'Odd']
[]
خطر شائع: map object بيتستهلك (consumed) بمجرد ما تلفّه مرة — لو عايز تستخدم النتيجة أكتر من مرة خزّنها في list أول ما تجيبها.
list_comprehension.py
# نفس نتيجة map، بس list comprehension
[check(i) for i in lst]
▸ Output
['Odd', 'Even', 'Odd', 'Even', 'Odd', ...]
map مقابل list comprehension: الاتنين بيرجعوا نفس النتيجة هنا. map مفيدة لما عندك دالة جاهزة عايز تطبّقها على كل عنصر، و list comprehension مفيدة لما عايز تكتب المنطق مباشرة في سطر واحد — ده مجرد أسلوب (style)، مفيش صح وغلط.
10

filter() و lambda

filter(function, seq) بترجّع بس العناصر اللي الدالة بترجّعلها True. لو الدالة بسيطة، ممكن تستبدلها بـ lambda في سطر واحد.

filter_def.py
def check_even(num):
    return num % 2 == 0

list(filter(check_even, lst))
# [2, 4]
filter_lambda.py
list(filter(lambda num: num % 2 == 0, lst))
# [2, 4] — نفس النتيجة، بسطر واحد
lambda_variable.py
x = lambda num: num % 2 == 0

x(10)   # True
x(11)   # False
▸ Output
x(10) → True
x(11) → False
الفرق بين map و filter: map بيحوّل كل عنصر لقيمة جديدة (نفس عدد العناصر)، أما filter فبينتقي بس العناصر اللي بتحقق شرط (عدد العناصر ممكن يقل).
filter_odd.py
def check_odd(num):
    if num % 2 != 0:
        return True

list(filter(check_odd, lst))
▸ Output
[1, 3, 3, 5, 5, 5, 7, 9]
لاحظ: check_odd ملهاش else — لو الشرط غلط الدالة بترجّع None تلقائيًا، وNone بيتحسب زي False جوه filter، فبرضه بتشتغل صح.
